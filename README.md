## 📂 Список проектов

### 1. 🏦 [Анализ банковских данных](https://github.com/your-username/bank-analysis)
Комплексный SQL-анализ клиентских счетов, портфелей менеджеров и кредитных рисков.

**Ключевые задачи:**
- Выявление топ-клиентов с балансом выше среднего
- Анализ активности счетов по городам
- Оценка кредитных рисков (обнаружен счет с 95% использованием лимита)
- Сводка по эффективности менеджеров

**Технологии:** SQL, Python, Jupyter Notebook

---

### 2. 🏠 [Анализ рынка недвижимости](https://github.com/your-username/real-estate-analysis)
Исследование цен на квартиры в 10 крупнейших городах России на основе 50+ объектов.

**Ключевые выводы:**
- Разница в ценах между Москвой/СПб и регионами — в 3-4 раза
- ТОП-10 самых дорогих квартир с детальными характеристиками
- Выявлены города с бюджетным жильем (< 5 млн руб.)

**Технологии:** Python, Pandas, NumPy, Jupyter Notebook

### 3. 🌤️ [API и Web Scraping](https://github.com/your-username/api-scraping-project)
Двойной проект: получение погодных данных для древнейших городов мира и парсинг интернет-магазина мебели.

**Часть 1 — Weather API:**
- Сбор данных о погоде в 5 исторических городах (Иерихон, Дамаск, Афины и др.)
- Анализ температуры, влажности и скорости ветра

**Часть 2 — Web Scraping:**
- Парсинг структуры сайта `boxx.ru`
- Извлечение каталога, цен, скидок и наличия товаров

**Технологии:** Python, requests, BeautifulSoup, OpenWeatherMap API

### 4. 🎮 [Анализ рынка видеоигр](https://github.com/your-username/video-games-analysis)
Исследование 16,715 игр (1980–2016) с анализом продаж по регионам, платформам и жанрам.

**Ключевые инсайты:**
- ТОП-10 самых продаваемых игр: Wii Sports (82.5 млн копий)
- Nintendo доминирует в топе (8 из 10 игр)
- Региональные предпочтения: RPG лидирует только в Японии
- Пик выпуска игр — 2008 год (1,427 игр)

**Технологии:** Python, Pandas, Jupyter Notebook

### 5. 📚 [Анализ онлайн-образования](https://github.com/your-username/online-education-analysis)
Анализ поведения студентов, успеваемости и выручки на основе данных о 110 слушателях курсов.

**Результаты:**
- Программирование приносит 30% всей выручки (1.58M ₽)
- Студенты с высоким completion_rate (90.4%) получают сертификаты
- Рекомендации приводят с самым высоким чеком (53,171 ₽)
- Динамика регистраций: пики в марте и мае

**Технологии:** Python, Pandas, Matplotlib, Seaborn

### 6. 🍽️ [EDA датасета Tips](https://github.com/your-username/tips-analysis)
Исследовательский анализ данных о чаевых в ресторане с интерактивным дашбордом.

**Ключевые выводы:**
- Положительная корреляция между счётом и чаевыми (0.68)
- Курящие женщины оставляют самый высокий процент чаевых (18.22%)
- Созданы новые признаки: процент чаевых, чаевые на человека
- Интерактивный мини-дашборд в Plotly

**Технологии:** Python, Pandas, Seaborn, Plotly, Google Colab
