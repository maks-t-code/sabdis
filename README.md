# Data Analytics & Web Integration Portfolio



Добро пожаловать в репозиторий-компендиум, объединяющий решения в области **Data Analytics, BI-визуализации, парсинга данных и работы с СУБД**. В данном портфолио представлены четыре независимых промышленных модуля, каждый из которых решает конкретную бизнес-задачу: от глубокого аудита банковских рисков до разработки интерактивных сквозных дашбордов для EdTech и ресторанного бизнеса.

---

## 📂 Структура репозитория и навигация

Портфолио разбито на изолированные директории. Вы можете перейти в каждую папку для ознакомления с подробной документацией, исходным кодом и примерами результатов:

1.  [**`01_bank_accounts_analytics/`**](./bank_accounts_analytics) — Комплекс аналитических SQL-запросов для банковского сектора.
2.  [**`02_real_estate_analytics/`**](./real_estate_analytics) — Модуль очистки и гео-сегментации рынка жилой недвижимости на Pandas.
3.  [**`03_web_integration_suite/`**](./web_integration_suite) — Набор скриптов для сбора данных (API OpenWeatherMap, BeautifulSoup4).
4.  [**`04_video_games_marketing/`**](./video_games_marketing) — Исследование игровой индустрии (EDA) с кросс-региональным профилированием.
5.  [**`05_edtech_funnel_analytics/`**](./edtech_funnel_analytics) — Анализ продуктовых метрик вовлеченности (COR) и воронки продаж онлайн-школы.
6.  [**`06_restaurant_tips_dashboard/`**](./restaurant_tips_dashboard) — Комплексный транзакционный анализ и интерактивный BI-дашборд на Plotly.

## 🛠️ Общий стек технологий и инструментов

В рамках портфолио продемонстрированы навыки работы со следующими технологическими стеками:

*   **Database Querying:** ANSI SQL (PostgreSQL / MySQL / SQLite) — подзапросы, условная агрегация, фильтрация данных, KPI-скоринг.
*   **Data Manipulation & ETL:** Python 3.x, Pandas, NumPy — продвинутая агрегация, решейпинг таблиц (`melt`, `pivot_table`), обработка временных рядов, очистка пропусков.
*   **Web Scraping & API Integration:** Requests, BeautifulSoup4 — парсинг DOM-структур, работа со сторонними REST API с обработкой сетевых исключений.
*   **Data Visualization & BI:** Plotly Express, Seaborn, Matplotlib — построение статических распределений (KDE, Boxplot) и интерактивных иерархических дашбордов (`sunburst`, `scatter`, `bar`).

## 🖥️ Краткий обзор модулей

### 1. Automated Bank Account Analytics (SQL)
*   **Задача:** Глубокий аудит, мониторинг портфеля и выявление операционных рисков в банковских базах данных.
*   **Результат:** Разработаны скрипты для VIP-сегментации, географического анализа покрытия, детекции «спящих» счетов (Churn Rate), расчета KPI менеджеров и многоуровневого скоринга рисков дефолта по кредитным линиям.

### 2. Real Estate Market Analytics (Pandas)
*   **Задача:** Обработка, очистка и кросс-региональное исследование рынка жилой недвижимости.
*   **Результат:** Реализован алгоритм поиска пропусков в физических характеристиках объектов, проведена ценовая сегментация (инвестиционные лоты до 5 млн руб.) и кросс-региональный анализ макроэкономических диспропорций стоимости жилья в крупнейших агломерациях.

### 3. Web Integration & Data Mining Suite (Requests / BS4)
*   **Задача:** Автоматизация сбора климатических и инфраструктурных данных из сети.
*   **Результат:** Создан отказоустойчивый асинхронный Geo-API клиент к OpenWeatherMap с обработкой HTTP-ошибок и семантический HTML-парсер табличных и навигационных данных веб-ресурсов.

### 4. Video Games Market Analytics (Pandas / EDA)
*   **Задача:** Ретроспективный анализ финансовых показателей и региональных диспропорций игровой индустрии (свыше 16 000 записей).
*   **Результат:** Локализованы года пиковой активности геймдева, рассчитана окупаемость жанров (сравнение валовых сборов и медианной стабильности) и составлены уникальные профили предпочтений для рынков Северной Америки, Европы и Японии с учетом возрастных рейтингов ESRB.

### 5. EdTech Sales & Student Engagement Analytics (Pandas / Seaborn)
*   **Задача:** Анализ воронки продаж, дисконтной политики и метрик успеваемости студентов онлайн-платформы.
*   **Результат:** Рассчитана сквозная продуктовая метрика COR (Completion Rate), определена зона критического оттока (COR ~49.7%) и составлены сводные финансовые матрицы, выявившие наиболее эффективные маркетинговые каналы (Word of Mouth) и доходные категории («Программирование»).

### 6. Restaurant Tips & Customer Behavior Analytics (Plotly / Dashboard)
*   **Задача:** Исследование факторов формирования чаевых и структуры выручки заведения.
*   **Результат:** Проведен Feature Engineering (расчет чека и чаевых на человека), исследованы корреляции между размером компании и вознаграждением. Построен интерактивный BI-дашборд, локализовавший ядро выручки ресторана с помощью иерархических `sunburst`-диаграмм.

## 📦 Порядок развертывания проекта

### Требования
*   Python версии 3.8 или выше
*   Установленная СУБД (для SQL-модуля) или IDE (DBeaver, DataGrip)

### Установка зависимостей
Склонируйте репозиторий и установите единый пакет библиотек, необходимых для запуска всех Python-компонентов:
```bash
git clone https://github.com<ваш_пользователь>/<название_репозитория>.git
cd <название_репозитория>
pip install -r requirements.txt
```
*(Примечание: файл `requirements.txt` содержит библиотеки `pandas`, `numpy`, `requests`, `beautifulsoup4`, `matplotlib`, `seaborn` и `plotly`).*
