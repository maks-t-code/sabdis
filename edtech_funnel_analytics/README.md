# EdTech Sales & Student Engagement Analytics (ESSEA)



**EdTech Sales & Student Engagement Analytics (ESSEA)** — это автоматизированный ETL и аналитический модуль на стыке Data Analytics и Product Management, предназначенный для исследования воронки продаж, поведенческих паттернов студентов и коммерческой эффективности онлайн-школы. Система исследует взаимосвязь между финансовыми показателями (базовые цены, скидочная политика, LTV) и продуктовыми метриками (метрики вовлеченности COR, успеваемость, удовлетворенность пользователей).

---

## 🚀 Ключевые возможности

*   🧹 **Первичный аудит и типизация данных** — автоматическое выявление пропусков, расчет описательной статистики и приведение временных рядов (`registration_date`) к оптимизированным типам данных для работы с временными окнами.
*   📅 **Когортный и временной анализ** — извлечение календарных признаков (дни недели, месяцы регистраций) для построения динамики притока пользователей и выявления сезонных колебаний спроса.
*   💵 **Ценовой аудит и оптимизация прайсинга** — исследование плотности распределения итоговой стоимости курсов (`final_price`), расчет медианы и среднего для оценки влияния агрессивного дисконтирования и премиум-сегментов на выручку.
*   📈 **Продуктовый скоринг вовлеченности (Completion Rate)** — расчет сквозной метрики COR (доли завершенных уроков) и сдача домашних заданий для ранжирования студентов и прогнозирования Churn Rate.
*   🎯 **Бизнес-анализ эффективности каналов и курсов** — когортный анализ выручки по категориям, вычисление финансовой емкости источников привлечения (`lead_source`) и аудит удовлетворенности (`satisfaction_score`) для оптимизации маркетингового бюджета.

## 🛠️ Стек технологий

*   **Язык разработки:** Python 3.x
*   **Обработка данных:** Pandas (Advanced Aggregations, Pivot Tables, Datetime operations)
*   **Статистика и вычисления:** NumPy
*   **Визуализация данных:** Matplotlib, Seaborn (распределения, плотность ядра KDE, временные тренды)

## 📊 Структура данных (online_education_sales.csv)

Датасет содержит 110 уникальных записей о студентах за полугодовой интервал по 20 ключевым бизнес-метрикам:

| Категория | Столбец | Описание |
| :--- | :--- | :--- |
| **Профиль студента** | `student_id` <br> `age` <br> `gender` <br> `city` | Идентификатор, возраст, пол и географическая локация пользователя. |
| **Маркетинг & Продажи** | `registration_date` <br> `lead_source` <br> `course_price` <br> `discount_percent` <br> `final_price` <br> `payment_type` | Дата регистрации, лид-канал, базовая и финальная цена с учетом скидки, тип оплаты (карта / рассрочка). |
| **Продуктовые метрики** | `course_name` <br> `course_category` <br> `lessons_total` <br> `lessons_completed` <br> `homeworks_submitted` | Название и категория курса, общий объем программы, пройденные уроки и сданные ДЗ. |
| **Фидбек & Успеваемость**| `support_requests` <br> `days_to_purchase` <br> `satisfaction_score` <br> `certificate_received` | Обращения в саппорт, скорость принятия решения о покупке, CSI-метрика и факт успешного окончания. |

## 📦 Быстрый старт & Примеры использования

### 1. Предобработка и обогащение временных рядов
```python
import pandas as pd

# Импорт массива данных и конвертация временных меток
data = pd.read_csv('online_education_sales.csv')
data['registration_date'] = pd.to_datetime(data['registration_date'])

# Генерация производных фичей для временного анализа
data['registration_weekday'] = data['registration_date'].dt.weekday
data['registration_month'] = data['registration_date'].dt.month
```

### 2. Расчет продуктовой метрики COR (Completion Rate)
```python
# Расчет индивидуального прогресса вовлеченности студента
data['completion_rate'] = data['lessons_completed'] / data['lessons_total']

# Сравнительный анализ COR для успешных и оттоковых студентов
completion_by_cert = data.groupby('certificate_received')['completion_rate'].mean()
print(completion_by_cert)
```

### 3. Сводный финансовый аудит категорий и каналов
```python
# Анализ валовой выручки по продуктовым направлениям
revenue_by_category = data.pivot_table(index='course_category', values='final_price', aggfunc='sum')

# Расчет среднего чека (AOV) по маркетинговым каналам привлечения
aov_by_lead_source = data.pivot_table(index='lead_source', values='final_price', aggfunc='mean')
```

## 📈 Ключевые аналитические выводы

### I. Анализ динамики регистраций и прайсинга
*   **Временные тренды:** Исследуемый полугодовой массив данных указывает на выраженную активность пользователей весной — пиковые значения притока регистраций зафиксированы в **марте** и **мае**.
*   **Структура ценообразования:** Распределение базовой стоимости курсов имеет бимодальный характер с концентрацией вокруг ценовых сегментов в **45 000 руб.** и **69 000 руб.**
*   **Скидочный компромисс:** Средний чек (`final_price`) составляет **47 731 руб.**, а медиана — **47 400 руб.** Полное совпадение этих метрик доказывает симметричность распределения: платформа не имеет экстремальных выбросов цен. Итоговое распределение чека формируется преимущественно гибкой купонной политикой и скидками, а не дорогими лотами.

### II. Продуктовые метрики вовлеченности (COR)
*   **Общий прогресс:** Средний показатель COR по платформе равен **75.2%**, при этом медиана достигает **81.9%**. Это свидетельствует об устойчивом ядре аудитории — более половины студентов завершают свыше 4/5 всей программы курса.
*   **Критерий сертификации:** Выявлен жесткий водораздел в метриках вовлеченности: студенты, успешно получившие сертификат, имеют средний COR **90.4%**. Студенты без сертификатов бросают обучение на экваторе, демонстрируя средний COR всего **49.7%** (зона критического оттока).

### III. Эффективность бизнес-направлений
*   **Драйверы выручки:** Абсолютным лидером по генерации валового дохода является категория **«Программирование»** (1.58 млн руб.), на втором месте — **«Аналитика»** (1.11 млн руб.). Наименьшую выручку приносит «Маркетинг» (0.76 млн руб.).
*   **Качество лидов:** Канал **«Рекомендация» (Word of Mouth)** демонстрирует наивысший средний чек — **53 171 руб.**, что подтверждает максимальную целевую лояльность аудитории, пришедшей по реферальным программам. Самый низкий чек — у социальных сетей (45 661 руб.).
*   **Удовлетворенность (CSI):** Наивысший средний уровень удовлетворенности клиентов зафиксирован на курсе **Project Management (7.94 из 10)** и на направлении **Data Analytics (7.84 из 10)**. Самый низкий балл — у базовых курсов по Python (7.00 из 10), что требует переработки начальных модулей программы.
