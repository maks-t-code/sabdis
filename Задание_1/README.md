# Анализ банковских данных

Проект по анализу банковских данных с использованием SQL. Реализован в формате Jupyter Notebook и включает комплексный анализ клиентских счетов, портфелей и рисков.

## 📊 Описание задач

### 1. Интересные счета для менеджера
Выявление клиентов, чьи счета представляют особый интерес:
- Активный статус счета
- Известное местоположение клиента
- Баланс выше среднего по активным счетам

**Результат:** 10 клиентов с наибольшими депозитами, включая лидера с балансом 1 000 000 RUB.

### 2. Анализ городов
Оценка клиентской базы по городам с минимум 3 счетами:
- Количество счетов
- Общая и средняя сумма балансов
- Количество активных счетов

**ТОП городов:**
- Москва: 11 счетов, 1.9M RUB общий баланс
- Санкт-Петербург: 4 счета, 1.6M RUB общий баланс
- Казань: 5 счетов, ~1M RUB общий баланс

### 3. Просроченные операции
Поиск счетов, требующих внимания из-за отсутствия операций:
- Счета без операций (`Нет операций`)
- Операции были давно (до 2024-03-01)
- Только активные счета

**Результат:** 18 счетов требуют проверки, преимущественно депозитные счета.

### 4. Портфель менеджеров
Сводка по каждому менеджеру:
- Количество ведомых счетов
- Активные счета
- Суммарный и средний баланс
- Клиенты без указания города

**Лидеры:**
- Анна Смирнова: 14 счетов, 3.7M RUB
- Олег Васильев: 13 счетов, 909K RUB
- Ирина Орлова: 13 счетов, 865K RUB

### 5. Риск-анализ кредитов
Выявление кредитных счетов с повышенным риском:
- Использовано > 60% кредитного лимита
- Отрицательный баланс
- Оценка уровня риска

**Результат:** Обнаружен счет с 95% использованием кредитного лимита (высокий риск).

## 📝 Пример SQL-запроса

Анализ кредитных рисков:

```sql
SELECT account_id,
  client_name,
  balance,
  credit_limit,
  ROUND((ABS(balance) / credit_limit) * 100, 2) AS usage_limit_percent,
  CASE
    WHEN (ABS(balance) / credit_limit) * 100 > 90 THEN 'Высокий'
    WHEN (ABS(balance) / credit_limit) * 100 >= 75 THEN 'Средний'
    ELSE 'Умеренный'
  END AS risk_level
FROM bank_accounts
WHERE account_type = 'credit'
  AND credit_limit > 0
  AND balance < 0
  AND ABS(balance) > 0.6 * credit_limit
```
