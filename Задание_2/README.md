# 📊 Анализ рынка недвижимости

Анализ данных о продажах квартир в крупнейших городах России. Проект включает исследование цен, характеристик жилья и региональных особенностей рынка недвижимости.

## 📋 Описание датасета

Датасет содержит информацию о **50 квартирах** в **10 городах России** со следующими характеристиками:

| Поле | Описание |
|------|----------|
| `id` | Уникальный идентификатор квартиры |
| `city` | Город расположения |
| `district` | Район города |
| `metro` | Ближайшая станция метро |
| `rooms` | Количество комнат |
| `total_area_m2` | Общая площадь (м²) |
| `living_area_m2` | Жилая площадь (м²) |
| `kitchen_area_m2` | Площадь кухни (м²) |
| `price_rub` | Цена в рублях |

## 📈 Ключевые выводы

1. **Ценовое неравенство**: Разница между самым дорогим (Санкт-Петербург) и самым дешевым (Самара) городом составляет **13.6 млн руб.**

2. **Столичный разрыв**: Средняя цена в Москве и Санкт-Петербурге в 3-4 раза выше, чем в регионах

3. **Бюджетный сегмент**: В 7 городах есть квартиры дешевле 5 млн руб., включая просторные варианты (до 51 м²)

4. **Качество данных**: Пропуски в столбце `metro` связаны с отсутствием метро в некоторых городах и не критичны для анализа

## 🚀 Установка и запуск

```bash

```

2. **Создайте виртуальное окружение**

