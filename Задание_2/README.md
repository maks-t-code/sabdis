# Real Estate Market Analytics (REMA)



**Real Estate Market Analytics (REMA)** — это автоматизированный аналитический инструмент на базе библиотеки `pandas`, предназначенный для обработки, очистки и комплексного исследования кросс-региональных данных о рынке жилой недвижимости. Система агрегирует ключевые метрики стоимости, проводит сегментацию по географическим признакам и выявляет скрытые ценовые аномалии в крупнейших городах РФ.

---

## 🚀 Ключевые возможности

*   🧭 **Многомерный гео-анализ** — сквозное исследование параметров жилья (метраж, комнатность) в разрезе городов, районов и станций метрополитена.
*   📉 **Аудит качества данных** — автоматическое обнаружение пропусков в ключевых физических и инфраструктурных характеристиках объектов (жилая площадь, зоны кухонь, метро).
*   💵 **Ценовая сегментация** — динамическая фильтрация и выборка объектов под заданные инвестиционные лимиты (например, поиск лотов стоимостью до 5 млн рублей с площадью более 50 м²).
*   🔝 **Ранжирование премиального сегмента** — выделение ТОП-позиций межрегионального рынка недвижимости на основе автоматической сортировки ценовых диапазонов.
*   📊 **Группировка и бизнес-метрики** — расчет усредненных индикаторов стоимости квадратного метра и объектов для сравнительного макроэкономического анализа регионов.

## 🛠️ Стек технологий

*   **Язык разработки:** Python 3.x
*   **Аналитическое ядро:** Pandas (DataFrames, GroupBy, Advanced Indexing)
*   **Вычислительные методы:** NumPy (обработка null-значений через `np.nan`)
*   **Среда выполнения:** Jupyter Notebook / Google Colab

## 📊 Структура данных (Датасет)

Входящий массив содержит информацию о 50 уникальных объектах недвижимости, каждый из которых описывается 9 ключевыми параметрами:

| Поле | Тип данных | Описание |
| :--- | :--- | :--- |
| `id` | Integer | Уникальный идентификатор квартиры |
| `city` | String / Category | Город присутствия |
| `district` | String | Административный район |
| `metro` | String | Ближайшая станция метрополитена |
| `rooms` | Float / Integer | Количество жилых комнат |
| `total_area_m2` | Float | Общая площадь объекта (кв. м) |
| `living_area_m2`| Float | Жилая площадь объекта (кв. м) |
| `kitchen_area_m2`| Float | Площадь кухни (кв. м) |
| `price_rub` | Integer | Финальная рыночная стоимость лота (руб.) |

### 1. Проверка качества данных и структуры пропусков
Инструмент позволяет локализовать пропущенные значения, способные исказить финальную оценку рыночной стоимости.
```python
# Расчет абсолютного количества пропусков в разрезе признаков

```

### 2. Локальный гео-скоринг (Пример: Москва)
Выделение изолированных региональных кластеров и поиск максимальных ценовых экстремумов внутри них.
```python
df_moscow = df[df['city'] == 'Москва']
premium_moscow_lot = df_moscow.sort_values('price_rub', ascending=False).head(1)
```

### 3. Поиск недооцененных активов и инвестиционных лотов
Выборка объектов в заданном бюджетном коридоре (до 5 000 000 руб.) с фильтрацией по повышенной жилой площади.
```python
df_low_price = df.loc[df['price_rub'] < 5000000, ['city', 'district', 'rooms', 'total_area_m2', 'price_rub']]
large_budget_apartments = df_low_price[df_low_price['total_area_m2'] > 50]
```

### 4. Кросс-региональный сравнительный анализ стоимости
Сводная группировка по городам для оценки макроэкономических диспропорций в стоимости жилья.
```python
regional_price_index = df.groupby('city')['price_rub'].mean().reset_index().sort_values('price_rub', ascending=False)
print(regional_price_index)
```
