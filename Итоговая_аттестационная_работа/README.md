# Restaurant Tips & Customer Behavior Analytics



**Restaurant Tips & Customer Behavior Analytics** — это комплексный аналитический модуль для проведения сквозного разведочного анализа данных (EDA) и построения интерактивных мини-дашбордов на основе исторических данных о ресторанных транзакциях. Проект исследует поведенческие паттерны клиентов, факторы формирования чаевых и структуру выручки в зависимости от демографических, временных и поведенческих характеристик аудитории.

---

## 🚀 Ключевые возможности

*   🧹 **Аудит и верификация качества данных** — экспресс-анализ структуры, проверка пропусков, оценка дубликатов и валидация распределений категориальных признаков.
*   📐 **Прогрессивный Feature Engineering** — генерация относительных продуктовых и финансовых метрик (`tip_percent`, `bill_per_person`, `tip_per_person`) для более точного профилирования клиентов.
*   📊 **Многомерный статистический анализ** — оценка плотности распределений, медианных и средних значений, а также автоматический поиск выбросов и экстремальных значений чека через `boxplot`-анализ.
*   🔗 **Корреляционный скоринг** — построение тепловых карт (`heatmap`) и диаграмм разброса с линиями регрессии для установления силы связи между размером компании, суммой счета и вознаграждением персонала.
*   🖥️ **Интерактивный BI-Дашборд** — разработка динамических визуализаций (включая иерархические диаграммы `sunburst`), раскрывающих долевой вклад каждого клиентского сегмента в общую структуру доходов.

## 🛠️ Стек технологий

*   **Язык разработки:** Python 3.x
*   **Аналитическое ядро:** Pandas (Advanced Grouping & Pivot Tables)
*   **Статистические методы:** NumPy
*   **Статическая визуализация:** Matplotlib, Seaborn
*   **Интерактивный дашборд:** Plotly Express (Sunburst, Interactive Scatter/Box/Bar)

## 📊 Структура данных и спецификация метрик

Аналитическое ядро обрабатывает данные о транзакциях по следующим направлениям:

| Группа признаков | Столбец | Описание |
| :--- | :--- | :--- |
| **Базовые метрики сбора** | `total_bill` <br> `tip` <br> `size` | Общая сумма счета (\$), размер чаевых (\$) и количество человек в компании. |
| **Категориальные маркеры** | `sex` <br> `smoker` <br> `day` <br> `time` | Пол плательщика, статус курения, день недели, время посещения (обед/ужин). |
| **Генерируемые метрики** | `tip_percent` <br> `bill_per_person` <br> `tip_per_person` | Процент чаевых от счета, сумма чека на одного человека, сумма чаевых на одного человека. |

## 📦 Быстрый старт & Примеры использования

### 1. Загрузка данных и Feature Engineering
```python
import pandas as pd
import seaborn as sns

# Инициализация датасета
df = sns.load_dataset('tips')

# Генерация аналитических фичей
df['tip_percent'] = df['tip'] / df['total_bill'] * 100
df['bill_per_person'] = df['total_bill'] / df['size']
df['tip_per_person'] = df['tip'] / df['size']
```

### 2. Корреляционный анализ числовых признаков
```python
import matplotlib.pyplot as plt

# Расчет матрицы и визуализация тепловой карты
corr_matrix = df.select_dtypes(include='number').corr()
sns.heatmap(corr_matrix, annot=True, cmap="Greens")
plt.show()
```

### 3. Построение интерактивного иерархического дашборда
```python
import plotly.express as px

# Визуализация структуры выручки: День -> Время -> Статус курения
fig = px.sunburst(df, path=['day', 'time', 'smoker'], values='total_bill',
                  color='total_bill', color_continuous_scale='RdBu', title='Иерархическая структура выручки ресторана')
fig.show()
```

## 📈 Ключевые аналитические выводы

### I. Структура распределений и качество данных
*   **Проверка качества:** Входной массив данных характеризуется высоким качеством, пропуски отсутствуют. Обнаруженные единичные дубликаты соответствуют естественным повторениям транзакций.
*   **Специфика распределений:** Финансовые показатели (`total_bill`, `tip`) имеют выраженную правостороннюю ассиметрию с длинными «хвостами» крупных чеков (вплоть до $50.81). Медианный чек составляет **17.80 $**, а средний — **19.79 $**.
*   **Стандарты чаевых:** Медианный процент чаевых жестко зафиксирован на уровне **15.48%**, при этом среднее значение равно **16.08%**.

### II. Факторы коммерческой эффективности и корреляции
*   **Сила связи:** Зафиксирована сильная положительная корреляция между суммой общего счета и абсолютным размером чаевых (**0.68**). Количество гостей в компании также напрямую масштабирует общий чек (**0.60**).
*   **Регистры чаевых:** Относительный показатель чаевых (`tip_percent`) демонстрирует обратную связь с чеком: при мелких заказах процент вознаграждения часто возрастает.

### III. Сегментация аудитории и кросс-анализ факторов
*   **Пиковые периоды:** Максимальная концентрация транзакций приходится на субботу (87 заказов) и воскресенье (76 заказов). Выходные дни также лидируют по среднему чеку (до **21.41 $** в воскресенье), что обусловлено притоком больших компаний (`size` $\ge$ 3).
*   **Маркетинговые маркеры:** Самый высокий средний процент чаевых оставляют курящие женщины (**18.22%**). Напротив, курящие мужчины оставляют меньший процент вознаграждения (**15.28%**), чем некурящие (**16.07%**).
*   **Тайминг:** Вечернее время (Dinner) генерирует чеки и чаевые значительно выше дневного (Lunch), однако обеденное время востребовано преимущественно в будни (четверг).
*   **Долевой вклад в выручку:** Интерактивный `sunburst`-анализ структуры доходов показал, что стратегическое ядро выручки ресторана формируют **некурящие клиенты во время ужинов в субботу и воскресенье**.
