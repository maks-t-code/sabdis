
# Анализ датасета Tips 🍽️

Комплексный исследовательский анализ данных (EDA) датасета `tips` из библиотеки Seaborn. Проект включает в себя полную обработку данных, создание новых признаков, визуализацию зависимостей и интерактивный дашборд.

## 📊 Обзор проекта

Цель проекта — провести глубокий анализ поведения клиентов ресторана, выявить факторы, влияющие на размер чаевых, и визуализировать ключевые закономерности для презентации результатов.

### Основные этапы анализа

1. **Загрузка и описание данных**: знакомство со структурой датасета и его переменными.
2. **Проверка качества данных**: выявление пропусков, дубликатов и аномалий.
3. **Feature Engineering**: создание дополнительных метрик (`tip_percent`, `bill_per_person`, `tip_per_person`).
4. **Описательная статистика и распределения**: анализ числовых признаков с помощью гистограмм и boxplot'ов.
5. **Анализ категорий**: сравнение средних значений по категориальным признакам (пол, статус курения, день, время, размер компании).
6. **Корреляции и базовые зависимости**: построение матрицы корреляции и диаграмм рассеяния.
7. **Комбинированный анализ категорий**: исследование сочетаний факторов с помощью сводных таблиц и графиков с `hue`.
8. **Интерактивный мини-дашборд**: создание набора интерактивных графиков с помощью Plotly.

## 🛠️ Используемый стек

- **NumPy** — вычисления
- **Matplotlib & Seaborn** — статическая визуализация
- **Plotly** — интерактивные графики
- **Google Colab** — среда выполнения

## 📈 Ключевые выводы

- **Связь чаевых и счёта**: Устойчивая положительная корреляция между `total_bill` и `tip` (0.68). С ростом счёта увеличиваются и чаевые.
- **Влияние дня недели и времени**: Наибольшее количество заказов — в субботу; самый высокий средний счёт — в воскресенье. Чаевые за ужин стабильно выше, чем за обед.
- **Роль размера компании**: Размер группы (`size`) умеренно коррелирует с чаевыми (0.49) и напрямую влияет на абсолютную сумму чека.
- **Статус курения**: Курящие женщины оставляют самый высокий процент чаевых (18.22%). Влияние статуса курения на средний чек неоднородно по дням недели.
