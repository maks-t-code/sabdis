# 📚 Анализ онлайн-образования

Комплексный анализ данных об обучении на онлайн-курсах. Исследование включает анализ продаж, поведения студентов, эффективности обучения и факторов успешного прохождения курсов.

## 📊 Описание датасета

Датасет содержит информацию о **110 студентах**, зарегистрировавшихся на курсы в период с января по июнь 2024 года.

### Основные столбцы:

| Категория | Столбцы | Описание |
|-----------|---------|----------|
| **Студент** | `student_id`, `age`, `gender`, `city` | Данные о студентах |
| **Курс** | `course_name`, `course_category`, `course_price`, `discount_percent`, `final_price` | Информация о курсах и ценах |
| **Покупка** | `lead_source`, `payment_type`, `is_paid`, `days_to_purchase` | Данные о приобретении курса |
| **Обучение** | `lessons_total`, `lessons_completed`, `homeworks_submitted`, `completion_rate` | Прогресс обучения |
| **Результат** | `satisfaction_score`, `certificate_received` | Удовлетворенность и результат |

## 🔍 Ключевые инсайты

### 🎓 Успех обучения
1. **Сертификат получают 90.4% студентов** с высоким completion_rate
2. Студенты без сертификата проходят в среднем **только 50%** курса
3. Основной фактор успеха — **последовательное прохождение уроков**

### 💼 Бизнес-показатели
1. **Программирование** — самый прибыльный сегмент (1.58M ₽)
2. **Рекомендации** приводят студентов с самым высоким чеком (+12% к среднему)
3. **Ценовая политика** стабильна и не зависит от сезона

### 👥 Поведение студентов
1. **Пик регистраций** приходится на март и май
2. **Удовлетворенность** выше на курсах по управлению и аналитике
3. Студенты с высоким completion_rate **чаще получают сертификат**

## 📊 Примеры запросов

### Анализ выручки по категориям
```python
data.pivot_table(
    index='course_category',
    values='final_price',
    aggfunc='sum'
).sort_values('final_price', ascending=False)
```

### Анализ успеваемости по сертификатам
```python
data.groupby('certificate_received')['completion_rate'].mean()
```

### Ценовая динамика по месяцам
```python
data.pivot_table(
    index='registration_month',
    values='final_price',
    aggfunc='median'
)
```
