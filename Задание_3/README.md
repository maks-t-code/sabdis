# Web Integration & Data Mining Suite (WIDMS)



**Web Integration & Data Mining Suite (WIDMS)** — это утилитарный набор скриптов на Python, предназначенный для автоматизации сбора данных из сети. Пакет включает в себя два изолированных компонента: модуль интеграции с гео-аналитическим API для мониторинга метеоусловий и отказоустойчивый парсер (scrapper) для семантического анализа и извлечения контента из HTML-структур.

---

## 🚀 Ключевые возможности

*   🌤️ **Асинхронный Geo-API Клиент** — интеграция с OpenWeatherMap API для мониторинга климатических показателей (температура, влажность, барометрические данные, скорость ветра) по динамическому списку локаций.
*   🛡️ **Отказоустойчивая сетевая логика** — встроенная обработка исключений при работе с HTTP-протоколом (`Timeout`, `ConnectionError`, `HTTPError`, `JSONDecodeError`).
*   🕸️ **Семантический парсинг DOM** — автоматизированный краулинг веб-страниц с использованием `BeautifulSoup4` для экстракции ключевых узлов: заголовков (H1–H6), мета-тегов (`title`), гиперссылок, кнопок, параграфов и контентных списков (`ul`/`ol`).
*   📊 **Парсинг табличных данных** — интеллектуальное извлечение структурированной текстовой информации из HTML-таблиц (`<table>`, `<tr>`, `<td>`, `<th>`) с конвертацией в плоские массивы.

## 🛠️ Стек технологий

*   **Язык разработки:** Python 3.x
*   **Сетевое взаимодействие:** Requests (с кастомизацией `headers` и `timeout`)
*   **Обработка HTML:** BeautifulSoup4 (пакет `bs4`, парсер `html.parser`)

## 📋 Структура программных модулей

### Модуль 1: Клиент прогнозирования погоды (Weather API)
Использует эндпоинты OpenWeatherMap для интернационализированного сбора метеоданных в метрической системе. По умолчанию настроен на мониторинг древнейших агломераций мира.

```python
import requests

def get_weather(city, api_key):
    url = "http://openweathermap.org"
    params = {"q": city, "appid": api_key, "units": "metric", "lang": "ru"}
    response = requests.get(url, params=params, timeout=10)
    response.raise_for_status()
    return response.json()
```

### Модуль 2: Структурный HTML-анализатор (DOM Scraper)
Изолирует структуру веб-ресурса, выполняя сбор текстовых блоков, реестра товаров, списков навигации и служебных элементов интерфейса.

```python
from bs4 import BeautifulSoup
import requests

def parse_web_structure(url):
    headers = {'User-Agent': 'Mozilla/5.0'}
    response = requests.get(url, headers=headers, timeout=10)
    soup = BeautifulSoup(response.content, 'html.parser')
    
    # Сбор иерархических списков навигации
    u_lists = soup.find_all('ul')
    return [ul.get_text(strip=True) for ul in u_lists]
```

## 📦 Быстрый старт

### Требования
*   Python 3.8 или выше
*   Установленные зависимости: `pip install requests beautifulsoup4`
*   Действующий токен доступа (API Key) от OpenWeatherMap

### Запуск скрипта аналитики
1. Склонируйте репозиторий.
2. Укажите ваш действующий `API_KEY` внутри исполняемого модуля.
3. Запустите выполнение интересующего скрипта:
```bash
python weather_analytics.py
python dom_parser.py
```
