# 🎮 Анализ рынка видеоигр

Комплексный анализ данных о продажах видеоигр с 1980 по 2016 год. Исследование включает очистку данных, анализ продаж по регионам, платформам и жанрам, а также выявление ключевых трендов игровой индустрии.

## 📊 Описание датасета

Датасет содержит информацию о **16,715 играх** с 1980 по 2016 год.

| Столбец | Описание |
|---------|----------|
| `Name` | Название игры |
| `Platform` | Платформа (PS, Xbox, Wii, PC и др.) |
| `Year_of_Release` | Год выпуска |
| `Genre` | Жанр игры |
| `NA_sales` | Продажи в Северной Америке (млн копий) |
| `EU_sales` | Продажи в Европе (млн копий) |
| `JP_sales` | Продажи в Японии (млн копий) |
| `Other_sales` | Продажи в других регионах (млн копий) |
| `Critic_Score` | Оценка критиков (0–100) |
| `User_Score` | Оценка пользователей (0–10) |
| `Rating` | Возрастной рейтинг ESRB |

## 🔍 Проблемы и обработка данных

### Обнаруженные пропуски:
- `Critic_Score` - 8,578 пропусков (51.3%)
- `User_Score` - 6,701 пропусков (40.1%)
- `Rating` - 6,766 пропусков (40.5%)
- `Year_of_Release` - 269 пропусков

### Очистка данных:
1. Приведены названия столбцов к нижнему регистру
2. `user_score`: заменено 'tbd' → NaN, преобразовано в числовой тип
3. `year_of_release`: преобразован в целочисленный тип
4. Добавлен столбец `total_sales`
5. Пропуски в `rating` заменены на 'Unknown'
