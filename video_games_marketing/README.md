# Video Games Market Analytics (VGMA)



**Video Games Market Analytics (VGMA)** — это специализированный аналитический инструмент на базе библиотеки `pandas`, предназначенный для ретроспективного анализа исторического развития, финансовых показателей и региональных диспропорций игровой индустрии (период с 1980 по 2016 год). Система автоматизирует полный цикл разведочного анализа данных (EDA), включая предобработку типов, фильтрацию скрытых заглушек, оценку емкости платформ и расчет кросс-региональных потребительских предпочтений.

---

## 🚀 Ключевые возможности

*   🧹 **Промышленная предобработка данных** — перевод признаков в нижний регистр, детекция и корректное замещение текстовых заглушек (`tbd` -> `np.nan`) с последующим приведением к оптимизированным типам данных с поддержкой NULL (`Int64`, `Float64`).
*   📈 **Интегральный коммерческий скоринг** — расчет сквозной глобальной метрики `total_sales` на базе агрегации независимых рынков сбыта (Северная Америка, Европа, Япония и другие регионы).
*   🧭 **Макроэкономический анализ платформ** — комплексная группировка технических экосистем по валовой выручке, числу выпущенных тайтлов и медианной окупаемости одной игры.
*   🎭 **Сегментация контентного рынка** — ранжирование жанрового портфеля для локализации наиболее прибыльных и масштабируемых игровых направлений.
*   🗺️ **Профилирование макрорегионов (Гео-аналитика)** — автоматическое выделение ТОП-5 жанровых предпочтений для каждого ключевого рынка и аудит влияния рейтингов ESRB на локальные объемы продаж.

## 🛠️ Стек технологий

*   **Язык разработки:** Python 3.x
*   **Аналитическое ядро:** Pandas (Advanced Aggregations, Melt, GroupBy, Sorting)
*   **Математические методы:** NumPy (векторизованная обработка пропущенных значений)
*   **Формат модулей:** Jupyter Notebook / Скрипты автоматизации

## 📊 Структура данных (games.csv)

Входящий массив содержит детальное описание релизов со следующей спецификацией признаков:

| Столбец | Тип в базе | Описание |
| :--- | :--- | :--- |
| `name` | Object / String | Уникальное наименование видеоигры |
| `platform` | Object / Category | Аппаратная целевая платформа |
| `year_of_release`| Int64 | Календарный год официального выпуска |
| `genre` | Object / Category | Жанровая принадлежность |
| `na_sales` | Float64 | Коммерческие сборы в Северной Америке (млн копий) |
| `eu_sales` | Float64 | Коммерческие сборы в Европейском союзе (млн копий) |
| `jp_sales` | Float64 | Коммерческие сборы в Японии (млн копий) |
| `other_sales` | Float64 | Коммерческие сборы в остальных странах (млн копий) |
| `critic_score` | Float64 | Сводный индекс профессиональных критиков (0–100) |
| `user_score` | Float64 | Средневзвешенный балл пользователей (0–10) |
| `rating` | Object / Category | Официальный возрастной ценз ассоциации ESRB |

## 📦 Быстрый старт & Примеры использования

### 1. Загрузка данных и инициализация профиля
```python
import pandas as pd
import numpy as np

# Импорт массива и приведение схемы к нижнему регистру
df = pd.read_csv('games.csv')
df.columns = (col.lower() for col in df.columns)

# Трансформация типов данных под стандарты аналитики
df['user_score'] = df['user_score'].replace('tbd', np.nan).astype('Float64')
df['year_of_release'] = df['year_of_release'].astype('Int64')
```

### 2. Расчет интегральной выручки и поиск абсолютных бестселлеров
```python
# Расчет глобального коммерческого показателя
df['total_sales'] = df['na_sales'] + df['eu_sales'] + df['jp_sales'] + df['other_sales']

# Извлечение абсолютного лидера на североамериканском рынке
top_na_game = df.loc[df['na_sales'].idxmax()]
```

### 3. Коммерческий аудит игровых платформ
Вычисление емкости платформ и медианных продаж для оценки стабильности аппаратных экосистем.
```python
df_platform = df.groupby('platform', as_index=False).agg(
    sum_sales=('total_sales', 'sum'),
    number_of_games=('name', 'count'),
    median_sales=('total_sales', 'median')
)
top_5_by_revenue = df_platform.sort_values('sum_sales', ascending=False).head(5)
```

### 4. Мультирегиональное исследование жанров (Кросс-табуляция)
```python
# Трансформация таблицы из широкого в длинный формат для гео-анализа
df_melted = df.melt(id_vars=['genre'], value_vars=['na_sales', 'eu_sales', 'jp_sales', 'other_sales'],
                    var_name='region', value_name='sales')

# Извлечение ТОП-5 прибыльных жанров для каждой макроэкономической зоны
top_genres_per_region = df_melted.groupby(['region', 'genre'])['sales'].sum().reset_index()
top_genres_per_region = top_genres_per_region.sort_values(['region', 'sales'], ascending=[True, False]).groupby('region').head(5)
```

## 📈 Ключевые аналитические выводы

В ходе первичного исследования исторического массива данных (16,715 записей) были зафиксированы следующие закономерности:
*   **Пик игровой индустрии:** Максимальная интенсивность релизов пришлась на **2008 год** (выпущено 1,427 коммерческих проектов).
*   **Глобальный лидер:** Платформа **PS2** занимает первую строчку по валовым сборам (1,255.77 млн копий), демонстрируя при этом высокую плотность заполнения рынка (2,161 игра).
*   **Жанровые диспропорции:** Жанр **Action** лидирует по суммарной выручке (1744.17 млн копий), однако наивысшую медианную окупаемость на один релиз демонстрирует жанр **Platform** (0.27 млн копий на проект), что свидетельствует о меньшем числе низкокачественных релизов в сегменте платформеров.
*   **Культурные различия рынков:** В то время как рынки Северной Америки (879.01 млн) и Европы (519.13 млн) безоговорочно выбирают жанр **Action**, внутренний рынок Японии демонстрирует уникальную изоляцию, где с колоссальным отрывом доминирует жанр **Role-Playing** (355.41 млн).
*   **Влияние ценза ESRB:** В Северной Америке, Европе и на остальных мировых рынках лидируют игры с рейтингом **E (Everyone)**. В Японии специфические условия дистрибуции приводят к лидерству категории **Unknown** (игры без явного рейтинга ESRB — 841.96 млн сборов), что указывает на преобладание локальных систем сертификации (CERO).
